CHAPTER 03 · AI APPLICATION

Function Calling 函数调用

让语言模型从“会回答”走向“会调用工具”。

本节学习进度3 / 6
先理解一个核心概念基础知识

模型负责决定调用什么，
程序负责真正执行。

Function Calling 让模型根据你的请求，生成符合工具定义的调用信息。应用程序执行对应工具，再把结果交还给模型，形成最终答复。

提出任务“帮我查天气”
模型选择工具生成函数名与参数
程序执行并回传获取结果，组织回答
别混淆：模型通常不会亲自运行代码。真正的工具执行由你的应用完成。

这一节，你会学到

解释 Function Calling 的工作原理 区分模型决策和工具执行 识别它适合解决的问题
